Manas — Admin set-up (one page, for KKD)

The Admin panel in the app (home menu ⋮ → Admin) approves and removes people, sets library levels and issues class codes. It works only once the v7 sheet script (v7 includes everything from v4–v6) is deployed on the MD1 secretary Google account. Until then the panel says Not connected yet — see setup. About 15 minutes, once. Nothing here costs money.

Before you start

  • Sign in to Google as the MD1 secretary account (the one that owns the sheet "Manas updates list"). Not the Halcyon account.
  • Have the file tools/manas-apps-script-v7.gs open on the laptop (Notepad is fine). Select all, copy.

1. Open the script project

  1. Go to script.google.com. You see "My projects". Open the project that holds the Manas updates script (it was made when email updates were set up; its name is usually Manas updates or Untitled project). If you cannot find it, open the sheet "Manas updates list" → Extensions → Apps Script.
  2. In the editor, click inside the code, press Ctrl+A then Ctrl+V so the whole old file is replaced by v6. Press Ctrl+S (💾 Save project).

2. Run setupAccess

  1. At the top of the editor there is a drop-down showing a function name (next to ▶ Run and 🐞 Debug). Click it and choose setupAccess.
  2. Click ▶ Run. The first time, Google asks for permission: Review permissions → choose the MD1 account → Advanced → Go to … (unsafe) → Allow. (It is your own script; "unsafe" only means Google has not reviewed it.)
  3. Wait for Execution completed in the log at the bottom. New tabs (Libraries, Grants, Groups, Devices, Agreements, Log, Keys) now exist in the sheet. Running it again is harmless.

3. Run setupKeys and save the secret

  1. In the same drop-down choose setupKeys → ▶ Run.
  2. The log shows one line KEYS_SECRET: … (a long code). Select the code only and copy it.
  3. On the laptop make the file C:\Users\Kewal\Kewal AI Projects\Manas\keys\manas-keys-secret.txt with that code as its only line (Notepad → Save as → All files → that name). The keys\ folder is never backed up or published. If Controlled Folder Access blocks Notepad, save to the Desktop and drag the file into keys\.
  4. Never paste the code anywhere else. If it leaks, run setupKeys again after deleting KEYS_SECRET under Project Settings → Script Properties, and tell Claude.

4. Redeploy (same web address)

  1. Top right: Deploy → Manage deployments.
  2. Click the ✏️ pencil on the existing deployment.
  3. Version → New version. Leave Execute as: Me and Who has access: Anyone. Click Deploy, then Done.
  4. The web-app URL must stay the one in web/config.json (…/exec). If you accidentally made a New deployment instead, copy its URL and send it to Claude — otherwise nothing else changes.

5. Test one approval

  1. On your own phone open Manas (your email is the super admin), home menu ⋮ → Admin. The Requests tab should load (empty is fine) instead of Not connected yet.
  2. From a second phone or a browser window (another email), open any 🔒 library → Request access → send.
  3. Back on your phone: Admin → Requests shows the request → Approve. On the second device tap Check again → the library opens.
  4. Admin → Log shows both lines. Done.

If something is wrong

  • Not connected yet still showing → step 4 was skipped, or an old deployment is live: Deploy → Manage deployments → the active one must say the latest version.
  • Only an admin can do that → you are signed in to Manas with an email that is not in SUPER_ADMINS in the script (kewal@…). Change the email in Manas (home menu → Email) to that one.
  • The log says run setupAccess first → step 2 again.
  • Anything else: send Claude the exact words from the log at the bottom of the editor.
